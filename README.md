# code_1 — 园区物资仓储管理系统

面向约 20 人内部使用的**园区/物业物资仓储管理系统**。基于 **Flask + SQLite + Jinja2 + 原生 CSS**（无前端框架，纯 HTML/CSS/原生 JS，浏览器直接打开）。

> 当前数据：武汉仓库园区物资，585 个物品 / 84 个真实库位（按楼栋·楼层·库位编号组织）。

## 系统由两个独立进程组成

| 进程 | 文件 | 端口 | 用途 | 登录 |
|---|---|---|---|---|
| 后台 | `app.py` | 5000 | 仓管全功能后台（出入库、库存、库位、盘点、报表等） | 需登录 |
| 领用门户 | `apply_app.py` | 5001 | 免登录公开页，员工扫码提交领用申请 | 免登录 |

两个进程共用同一个 `warehouse.db`；门户只能写一条领用申请单，读不到也改不了库存，因此可安全对外暴露。

## 快速启动（本地）

```powershell
pip install -r requirements.txt
python app.py          # 后台   → http://localhost:5000
python apply_app.py    # 领用门户 → http://localhost:5001
```

两个进程默认都用生产级 **waitress** 服务器；调试想用 Flask 开发服务器设环境变量 `FLASK_DEV=1`。

## 主要模块

- **主数据**：物品(SKU) / 仓库 / 库位（含楼栋·楼层·库位编号·用途·整改状态）/ 物品所属方·管理方 / 用户与岗位
- **业务链**：入库单 / 出库单 / 调拨 / 盘点 / 报损 / 领用申请（扫码门户转出库）
- **库存**：库存查询（按物品汇总，含仓库·单位）/ 库存流水（日期 + 物品 + 事件类型筛选）/ 物品明细页（含采购记录与出库流水）
- **所有列表/查询页统一分页**
- **库存预测**：移动平均 + 安全系数，按近 1/3/6 月日均出库估下月控制量
- **导出**：库存 / 流水 / 盘点 / 预测 支持 CSV / Excel，可选导出列
- **预警通知（6 渠道）**：站内 / 邮件 SMTP / 阿里云短信 / 企业微信 / QQ 机器人(OneBot) / WPS Webhook，可在「系统 → 通知渠道」配置 + 测试 + 配规则
- **数据导入**：支持从 WPS/Excel 批量导入主数据
- **自动备份**：APScheduler 每日 02:00 拷贝 `warehouse.db` 到 `backups/`；管理员页可手动备份；月初快照库存

> 说明：底层库存仍保留批次 / FIFO / 临期 等通用 WMS 机制；早期的「经营报表 Dashboard」自 v22 已下线，相关数据迁至「查询分析 → 库存查询 / 库存流水 / 库存预测」。

## 权限

3 角色 × 11 岗位；菜单权限持久化到 `menu_permission` 表，管理员在「系统 → 用户与权限」勾选授权；新用户 / 重置密码后首次登录强制改密。

## 定时任务（随后台 `app.py` 启动）

- 每日 09:00 预警扫描
- 每日 02:00 数据库备份
- 每月 1 日 01:00 库存快照
