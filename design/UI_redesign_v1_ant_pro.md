## 1. 设计哲学

### 为什么选 Ant Design Pro 风

| 维度 | 现状（工业风） | Ant Pro |
|---|---|---|
| 用户群对标 | 自创，无参照 | 阿里云 / 腾讯云 / 字节飞书后台 —— 你导师和同事一眼能识别 |
| 信息密度 | 中（卡片大、字大）| 高（小字号、密集表格、Tag 多色） |
| 角色定制 | 同一套首页 | 暗色侧栏 + 不同菜单/首页/快捷按钮 per 角色 |
| 视觉成熟度 | 看起来像练习项目 | 看起来像生产级内部系统 |
| 后续迭代 | 自创规范，自我维护成本高 | 有完整设计语言可参照，方便扩展 |

**关键差别一句话**：工业风像个木匠工坊 ASCII 报表，Ant Pro 像阿里云控制台。

### 设计原则（贯穿所有 mockup）

1. **角色优先**：不同角色看到完全不同的首页（KPI / 待办 / 快捷操作三大区都因角色而变）
2. **任务驱动**：欢迎语直接告诉用户"今天还有 X 件事要做"，不是空泛欢迎
3. **信息密度高但有层级**：数字大、标签密、留白少，但用色彩和粗细分主次
4. **告警明显**：红色/橙色/黄色三级，越紧急越显眼
5. **响应式过渡**：hover 阴影加深、卡片轻浮起、tab 下划线滑动——细节透出"精致"
