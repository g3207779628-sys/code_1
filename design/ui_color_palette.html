// DON'TS

4. 禁忌

不要这样做

  • ❌ 纯白背景占主导（除卡片内部），整体用 #FBFAF7 暖米白
  • ❌ 深色 sidebar（旧 Ant Pro 风的 #001529）
  • ❌ 蓝色（旧 Stripe 深墨蓝、Ant 蓝）
  • ❌ 深绿（旧工业风的 #2F4F3E）
  • ❌ border-radius > 12px
  • ❌ 装饰性 emoji（除非用户明确要）
  • ❌ 渐变背景（除欢迎页 hero 用 radial-gradient）
  • ❌ 阴影过重（最多 0 4px 16px rgba(217,119,55,0.12)）
