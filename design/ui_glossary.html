一致性 5 个

这些是"AI 改不全"的根本解决方案
单一真理源 single source of truth
同一个东西只在一处定义
30 个 HTML 各写一次改不全
// inbound.html .btn { background: #FF4500; } // outbound.html .btn { background: #FF4500; } // inventory.html .btn { background: #FF4500; }
放进 CSS 变量改一处全改
// style.css :root --accent: #FF4500; // 所有 .html .btn { background: var(--accent); } .tag { color: var(--accent); } .link { color: var(--accent); }
你项目的 SSOT: [ui_white_shared.css](ui_white_shared.css) 里的 14 个 CSS 变量。改色板只改这一个文件, 30 个页面自动跟着变。这就是为什么 AI 不会再"改不全"。
设计零件 design token
把"具体值"换成"语义名"
裸值"#FF4500" 意义不明
.btn-primary { background: #FF4500; padding: 8px 18px; border-radius: 4px; }
语义化 token名字会说话
.btn-primary { background: var(--accent); padding: var(--btn-pad); border-radius: var(--r-sm); }
语义名 > 具体值: 看到 var(--accent) 你知道这是"主色",换品牌时只改 :root,所有用了 accent 的地方一起变。
组件复用 component reuse
同样的 UI 用同一个 class
每页重写卡片5 套样式
// dashboard.html <div style="background: #FFF; border: 1px solid #ECECEC; padding: 14px; border-radius: 8px;"> // inventory.html <div style="background: #fff; padding: 16px; border-radius: 10px;">
都用 .card1 套样式
// dashboard.html <div class="card"> // inventory.html <div class="card"> // inbound.html <div class="card">
规则: 同一类元素同一个 class。检查方法: 让我跑 grep 找所有 inline style,把它们抽成 class。
