C 白底工业 hybrid

保留旧工业风的紧凑数据密度（mono 字体的数字 / 紧凑 badge），但底色用白、点缀换红橙。表格密度高、卡片小、信息量大。

🔁 与原"暖米白 + 橙色"版的关系

本版（红橙白）和原版（暖米橙）共用同一套版式、组件、菜单结构、页面布局。差异只在色板：底色由 #FBFAF7 推到 #FFFAF7（更接近白），accent 由偏黄的橘 #D97737 换成更鲜的红橙 #E94B2C。如需对比原版请查看 ui_redesign_index.html。

📋 选型建议

  • 如果公司日常**操作量大**（每天 10+ 张单据）→ 选 方案 B（红橙显眼，active 醒目）
  • 如果给老板/管理层**主要看报表**和总览 → 选 方案 A（纯净，关键信息一眼看到）
  • 如果**数据维度多、信息密度高**（多仓 + 多 SKU + 流水频繁）→ 选 方案 C（hybrid，密度最高）
  • **折中推荐**：方案 B + C 混合 — 工作台/欢迎页用 B 显眼风格，库存流水/盘点页用 C 密度风格
