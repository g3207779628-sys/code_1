数据库 schema

CREATE TABLE location ( id INTEGER PRIMARY KEY, warehouse_id INTEGER REFERENCES warehouse(id), building TEXT, -- 新加，可为空 floor TEXT, -- 新加，可为空 code TEXT NOT NULL, zone_type TEXT ); -- 查询 "1 号楼总在仓"： SELECT SUM(inv.on_hand) FROM inventory inv JOIN location l ON l.id=inv.location_id WHERE l.building='1 号楼'; -- 升级到 A 方案（如果将来真有 5 栋楼）： -- 1) 从 location.building 抽出 distinct 值建 building 表 -- 2) 加 building_id FK + 数据迁移 + drop building 字段
★ 优点
· 菜单零增项，认知负担最低（20 人团队尤其重要）
· 建库位 1 次填齐 4 个字段，效率最高
· 按楼栋查询 SQL GROUP BY l.building 一行搞定
· 将来真有需求可平滑升级 A 方案（数据迁移友好）
· 实装工作量极小：location 表 2 个 ADD COLUMN + 模板加 2 个 input
! 注意
· 楼栋名是自由文本，可能出现 "1栋 / 1号楼 / 1-栋" 不一致（治理靠提示语）
· 楼栋本身没法挂额外属性（如"管理员"、"地址"）—— 真需要时再升级 A 方案
· 改楼栋名需要 UPDATE 所有库位，不像 A 方案改 1 处
