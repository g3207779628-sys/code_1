// RECOMMENDED
推荐 方案 B（信息卡平衡）。理由：
① 用户卡显示"display_name + 岗位 + 加入时间"，每个登录用户都能感到"被认出来了"，比纯 hero 更有亲和力；
② 4 个快捷入口比 C 的 6 个磁贴更克制，不会让首页变成第二个 dashboard；
③ 实装工作量适中，hero 用 #D63A00 + 按钮用 #FF4500 的"双层橙红"层次清楚，符合用户"暗一点"的诉求。
④ 没工作台权限的用户至少看到 4 个快捷入口里他能用的那几个（按 menu_permission 表过滤后渲染），不会两手空空。
